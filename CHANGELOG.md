# Changelog

All notable changes to this project will be documented in this file.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-07-04

### Added
- Complete implementation of all 12 agentic design patterns
- Multi-provider LLM abstraction (OpenAI, Anthropic, Google, Ollama, OpenRouter)
- Production-grade shared framework in `src/agentic_patterns/`
- Chapter implementations: Prompt Chaining through Production Agent
- Full test suite: unit, integration, mock
- Docker Compose support for all services
- GitHub Actions CI/CD pipeline
- Streamlit playground for interactive experimentation
- Benchmark suite with latency, cost, and accuracy measurement
- Example applications: Customer Support, Research Assistant, Coding Assistant
- Complete documentation with architecture diagrams
